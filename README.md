# KisaanConnect - Smart Farming App 🌾

A comprehensive Flutter application designed to help farmers with modern agricultural practices through technology integration.

## Features ✨

### 🌐 Multi-Language Support
- **English, Hindi, and Punjabi** language selection
- Complete UI localization
- Language preference persistence

### 🌤️ Weather Information
- Mock weather data with realistic simulation
- 5-day weather forecast
- Temperature, humidity, and wind information
- Farming-specific weather advisories

### 💰 Market Pricing
- Real-time crop price simulation
- Interactive crop selection (Wheat, Rice, Corn, Tomato, Onion, Potato)
- Price trends with up/down indicators
- Market analysis and recommendations

### 🌱 Disease Detection
- Photo upload simulation (camera/gallery)
- AI-powered plant disease analysis simulation
- Detailed treatment recommendations
- Step-by-step treatment instructions

### 🧪 Fertilizer & Pesticide Guide
- Comprehensive product categories
- Usage guidelines and recommendations
- Organic and chemical options
- Expert advice integration

### 🤖 Intelligent Chatbot
- Agricultural assistant with smart responses
- Context-aware farming advice
- Multi-language support
- Covers crops, diseases, fertilizers, pests, and weather

## Quick Start 🚀

### Prerequisites
- Flutter SDK (3.0.0 or higher)
- Android Studio / VS Code
- Android/iOS device or emulator

### Running the App

1. **Navigate to the project directory:**
   ```bash
   cd C:\apps\KisaanConnect
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```

4. **For web (optional):**
   ```bash
   flutter run -d chrome
   ```

## App Flow 📱

1. **Language Selection**: Choose from English, Hindi, or Punjabi
2. **Home Dashboard**: Access all main features from a clean interface
3. **Feature Navigation**: Seamlessly navigate between:
